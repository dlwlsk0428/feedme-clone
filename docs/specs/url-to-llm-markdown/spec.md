# URL을 Markdown으로 변환해 LLM에 넘기기

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 보여 주고, 복사·다운로드하거나 ChatGPT·Claude로 바로 넘기는 한 화면짜리 서비스입니다.

- 결정 계약: [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md) 새 의존성 추가 시 버전 정책을 따릅니다.

## 사용자 흐름과 결과

1. **입력**: 사용자가 URL 입력란에 주소를 붙여넣고 변환합니다. 지우기 버튼을 누르면 입력, 결과, 오류가 모두 초기 상태로 돌아갑니다.
2. **변환**: 서버가 해당 페이지를 가져와 `defuddle`로 본문을 Markdown으로 추출합니다.
3. **결과 확인**: 페이지 제목과 저자가 담긴 헤더가 보이고, 그 아래에 렌더링된 Markdown이 보입니다.
4. **내보내기**
   - 복사하기: Markdown 원문을 클립보드에 복사합니다.
   - .md 다운로드: Markdown 원문을 `.md` 파일로 내려받습니다. 파일명은 페이지 제목에서 만듭니다.
   - ChatGPT로 열기 / Claude로 열기: 선택한 프롬프트(없을 수도 있음)를 본문 앞에 붙여 해당 LLM의 새 대화로 엽니다.
5. **프롬프트**: 프리셋 "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘"와 "직접 입력"을 고를 수 있고, 아무것도 고르지 않으면 본문만 넘깁니다. "직접 입력"을 고르면 텍스트 입력란이 나타납니다. 직접 입력한 문구는 저장하지 않으며 새로 고침이나 지우기 후에는 사라집니다.
6. **다크모드**: 화면 어디서든 보이는 토글로 라이트/다크를 전환합니다.

## 수용 기준

- 공개 기사 URL(예: `https://stephango.com/saw`)을 넣으면 제목 "Use the saw, fear the saw"와 저자 "Steph Ango"가 헤더에 나오고 본문이 Markdown으로 렌더링됩니다.
- 한국어 위키 문서처럼 긴 페이지도 변환에 성공하고 본문이 렌더링됩니다.
- 지우기 버튼을 누르면 입력란, 결과, 오류 메시지, 직접 입력 문구가 모두 비워집니다.
- 복사하기를 누르면 클립보드에 Markdown 원문이 들어가고 복사됐다는 피드백이 보입니다.
- .md 다운로드를 누르면 렌더링된 화면이 아니라 Markdown 원문이 담긴 파일이 내려받아집니다.
- 프롬프트가 있으면 "프롬프트, 빈 줄, 본문" 순서로 합쳐 넘기고, 없으면 본문만 넘깁니다. 프리셋은 한 번에 하나만 선택됩니다.
- "직접 입력" 선택 시에만 텍스트 입력란이 보이며, 입력란이 비어 있으면 프롬프트 없이 넘깁니다.
- 결과가 보이는 동안 프롬프트 선택과 내보내기 버튼 4개(복사하기, .md 다운로드, ChatGPT로 열기, Claude로 열기)가 하나의 바로 묶여 화면 아래에 고정되고, 본문을 스크롤해도 같은 자리에 보입니다. 결과가 없을 때(빈 상태, 변환 중, 오류)는 바가 보이지 않습니다.
- 합친 텍스트가 짧으면 URL 쿼리로 ChatGPT(`https://chatgpt.com/?q=`)·Claude(`https://claude.ai/new?q=`)를 새 탭으로 열어 입력란에 바로 채워지게 합니다.
- 합친 텍스트가 URL로 실을 수 있는 한도를 넘으면 전체를 클립보드에 복사하고 LLM 새 대화만 연 뒤, "클립보드에 복사했으니 붙여넣으세요"라는 안내를 보여 줍니다.
- 잘못된 URL, 가져오기 실패(접속 불가, 4xx/5xx 등), 본문을 추출하지 못한 경우에는 각각 이해할 수 있는 오류 메시지가 보이고 이전 결과는 남지 않습니다.
- 변환 중에는 진행 상태가 보이고 그동안 변환 버튼이 중복 실행되지 않습니다.
- 다크모드 토글로 화면 전체(렌더링된 Markdown 포함)가 읽기 좋게 전환됩니다.
- 좁은 화면에서도 입력, 결과, 내보내기 action이 숨겨지지 않고 순서대로 쌓입니다.

## 확정된 제약과 근거

- **`defuddle` 필수**: 본문 추출은 `defuddle`로 합니다. 사용자 요구 사항입니다.
- **서버에서 가져와 변환**: 브라우저는 다른 도메인 페이지를 CORS 때문에 직접 가져올 수 없으므로 서버가 HTML을 가져옵니다. Node에서는 `defuddle/node`와 DOM 구현(`linkedom`)을 쓰는 방식이 `https://stephango.com/saw`와 한국어 위키 문서에서 제목, 저자, Markdown 추출까지 동작하는 것을 스크래치 환경에서 확인했습니다(defuddle 0.19.6).
- **긴 글은 클립보드로 넘김**: 사용자가 확정했습니다. URL 길이 한도 때문에 긴 글은 쿼리로 못 싣고, 잘라서 보내면 요약·번역 결과가 불완전해지기 때문입니다.
- **프롬프트는 저장하지 않음**: 직접 입력은 1회용입니다. 프리셋 선택도 저장하지 않습니다.
- **내보내기 배치**: 프롬프트와 버튼 4개를 한 덩어리로 묶어 하단 고정 바에 둡니다. 긴 글에서도 스크롤 없이 바로 내보낼 수 있게 하려는 사용자의 선택입니다. 바가 좁은 화면에서 세로 공간을 차지하는 비용은 감수합니다. 칩은 한 줄로 가로 스크롤합니다.
- UI는 `ui-composition` 결정을 따라 shadcn 컴포넌트와 semantic token으로 구성합니다.

## 가정 (덮어쓸 수 있음)

- 쿼리 길이 한도는 합친 텍스트가 대략 6,000자 이하일 때만 쿼리로 넘기는 보수적 값으로 둡니다. 정확한 값은 구현에서 조정합니다.
- 다크모드는 첫 방문 시 OS 설정을 따르고, 사용자가 토글한 선택은 브라우저에 기억합니다. 기억하지 않는 방식이 필요하면 바꿉니다.
- 프롬프트 프리셋 문구는 화면에 보이는 이름 그대로("요약해줘" 등) 본문 앞에 붙입니다.
- 로그인 필요 페이지나 JavaScript로만 그려지는 페이지는 변환되지 않을 수 있고, 이때는 본문 추출 실패 오류로 처리합니다.
- ChatGPT·Claude의 쿼리 파라미터(`q`) 동작은 외부 서비스 사양에 달려 있어 구현 중 실제 열림을 확인하되, 로그인 상태까지는 검증하지 않습니다.

## 범위 밖

- 변환 이력 저장, 계정, 서버 측 저장소.
- 프롬프트 직접 입력의 저장, 프리셋 편집.
- ChatGPT·Claude 외 다른 LLM, API 직접 호출.
- 요청 제한, URL 허용 목록, 사설망 접근 차단 같은 보안 하드닝(학습용 템플릿 예산 밖).
- 로그인이 필요한 페이지와 PDF 변환.

## 남은 위험

- LLM 서비스의 쿼리 파라미터 사양이 바뀌면 "열기"가 입력란을 채우지 못할 수 있습니다.
- 일부 사이트는 서버의 요청을 막거나 본문이 비어 있게 응답해 추출에 실패합니다.
- 서버가 임의의 URL을 가져오는 구조라, 배포 시 사설망 접근 같은 문제를 별도로 다뤄야 합니다(이 스펙의 범위 밖).
