# URL을 Markdown으로 변환해 LLM에 넘기기 (보노보노 PPT 판)

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 보여 주고, 복사·다운로드하거나 ChatGPT·Claude로 넘기는 한 화면짜리 서비스입니다. 화면은 강의용으로 일부러 "최악의 UI/UX"를 보여 주는 보노보노 PPT 감성으로 만듭니다. 기능은 모두 실제로 동작하고, 단서와 일관성만 의도적으로 망가뜨립니다.

## Linked sources

- 승인된 프로토타입: [prototype.html](./prototype.html) 화면 구성, 문구, 상태(기본, 변환 중, 변환 결과, 긴 글 결과, 오류), 애니메이션, NEW!! 광고 모드, 보노보노 이미지를 규정합니다. 마크업은 참고용이며 구현 코드가 아닙니다.
- 결정 계약: [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md) 새 의존성 추가 시 버전 정책을 따릅니다.
- 결정 계약: [docs/decisions/ui-composition.md](../../decisions/ui-composition.md) 이 화면에는 **적용하지 않습니다**. 아래 "결정 계약과의 충돌"을 참고하세요.
- 외부 문서: https://defuddle.md/docs (defuddle 사용법)

## 사용자 흐름과 결과

1. **입력**: 사용자는 문장 속 점선 빈칸에 URL을 붙여넣습니다. 안내 문장은 평문 한 덩어리로 이어지며 번호 목록이 아닙니다.
2. **변환**: 서버가 해당 페이지를 가져와 `defuddle`로 본문을 Markdown으로 추출합니다.
3. **결과 확인**: 문장 속에 페이지 제목과 글쓴이가 나오고, 그 아래 작은 상자에 Markdown 본문이 표시됩니다.
4. **내보내기**: 복사(클립보드), .md 파일 다운로드, ChatGPT로 열기, Claude로 열기. 앞에 붙일 프롬프트는 선택 사항입니다.
5. **프롬프트**: 요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘 중 하나, 또는 직접 입력. 직접 입력한 문구는 저장하지 않는 1회용입니다.
6. **초기화**: 지우기 동작은 입력, 결과, 오류, 프롬프트 선택, 직접 입력 문구를 모두 초기 상태로 되돌립니다.
7. **다크모드**: 보노보노 그림의 눈을 누르면 라이트/다크가 전환됩니다.
8. **NEW!! 광고 모드**: 그림 아래 NEW!!를 누르면 구인 광고 전단 느낌(노란 배경, "위독하실 분", "급구", 빨간 "지금 변환하세요" 띠, 빨간 원 스티커 "미친")으로 바뀝니다. 스티커를 다시 누르면 원래 화면으로 돌아옵니다.

## 의도적으로 어기는 UI/UX 원칙

사용자 요청으로 아래를 일부러 어깁니다. 구현에서 "고치지" 않습니다.

- **직관성**: 버튼이 없고 모든 동작이 본문 속 글자색과 같은 밑줄 단어입니다(변환, 복사, 다운로드, 요약, 번역, 쉬운 설명, 직접 입력, ChatGPT, Claude, 처음으로 돌아가기). 커서도 바뀌지 않습니다.
- **단순성**: 가짜 메뉴바(도움말은 "없음"), 무지개 배경, WordArt풍 제목, 도는 🌀, 헤엄치는 🐟, 전광판, 구독·좋아요 문구를 넣습니다.
- **일관성**: 같은 종류의 동작이 다르게 반응합니다. 복사와 Claude 열기는 더블클릭, 변환·다운로드·ChatGPT 열기는 한 번 클릭, 입력란에서 Enter는 변환하지 않습니다.
- **피드백**: 변환 중에는 화면 표시가 없고 탭 제목만 "..."이 됩니다. 복사·다운로드에는 반응이 없고, 오류와 "길어서 복사됨" 안내는 8px 옅은 글씨입니다. 프롬프트 선택 표시도 없습니다.
- **접근성**: 반응형이 없는 고정 폭(880px)이고, 포커스 표시가 없으며, 무지개 위 글자는 읽기 어렵습니다.

**지켜야 할 최소선**: 위 의도 때문에 기능이 막혀서는 안 됩니다. 밑줄 단어에는 그 동작이 무엇이고 몇 번 클릭하는지가 같은 문장 안에 평문으로 적혀 있어야 합니다. 밑줄은 기능이 있는 단어에만 칩니다.

## 수용 기준

- 공개 기사 URL(예: `https://stephango.com/saw`)을 넣고 변환을 한 번 클릭하면 약 2초 안에 제목 "Use the saw, fear the saw"와 글쓴이 "Steph Ango", Markdown 본문이 나옵니다.
- 한국어 위키 문서처럼 긴 페이지도 변환에 성공합니다.
- 복사·다운로드·프롬프트·ChatGPT·Claude 설명 문단은 변환 전에도 항상 보입니다.
- 복사를 두 번 연속 클릭하면 클립보드에 Markdown 원문이 들어갑니다. 복사됐다는 알림은 없습니다.
- 다운로드를 한 번 클릭하면 렌더링된 화면이 아니라 Markdown 원문이 담긴 `.md` 파일이 내려받아집니다. 파일명은 제목에서 만듭니다.
- 프롬프트는 하나만 선택되고 다른 것을 클릭하면 바뀝니다. "직접 입력"을 클릭할 때만 입력 빈칸이 나타납니다. 비어 있으면 프롬프트 없이 넘깁니다.
- 프롬프트가 있으면 "프롬프트, 빈 줄, 본문" 순서로 합치고, 없으면 본문만 넘깁니다.
- 합친 텍스트가 짧으면 ChatGPT(`https://chatgpt.com/?q=`) 또는 Claude(`https://claude.ai/new?q=`)를 새 탭으로 열어 입력란이 채워집니다. 합친 텍스트가 한도(대략 6,000자)를 넘으면 전체를 클립보드에 복사하고 새 대화만 엽니다.
- ChatGPT 열기는 한 번, Claude 열기는 두 번 클릭입니다.
- 잘못된 URL이나 가져오기 실패, 본문 추출 실패 시 8px 옅은 글씨로 짧은 오류 문구가 보이고 이전 결과는 남지 않습니다.
- 처음으로 돌아가기를 클릭하면 입력, 결과, 오류, 프롬프트 선택, 직접 입력 문구가 모두 초기화됩니다.
- 보노보노의 눈을 클릭하면 다크모드가 전환됩니다. 안내 문장 "눈이 아프신 분은 보노보노의 눈을 보시면 됩니다."는 유지합니다.
- 슬라이드 번호("3 / 41" 같은 표기)는 화면 어디에도 없습니다.
- 보노보노 그림은 흰 배경이 투명 처리되어 배경 위에 바로 서 있습니다.
- 제목, 보노보노, NEW!!, 결과, 밑줄 단어, 🐟에 프로토타입과 같은 종류의 애니메이션이 있습니다. 시스템에서 "동작 줄이기"를 켠 사용자에게는 애니메이션이 꺼집니다.
- NEW!!를 누르면 광고 모드로 바뀌고 "미친" 스티커를 누르면 원래로 돌아옵니다. 광고 모드에서도 모든 기능이 동작합니다.

## 확정된 제약과 근거

- **`defuddle` 필수**: 본문 추출은 `defuddle`로 합니다. 사용자 요구 사항입니다.
- **서버에서 가져와 변환**: 브라우저는 다른 도메인 페이지를 CORS 때문에 직접 가져올 수 없으므로 서버가 HTML을 가져옵니다. Node에서는 `defuddle/node`와 DOM 구현(`linkedom`)을 쓰는 방식이 `https://stephango.com/saw`와 한국어 위키 문서에서 제목, 저자, Markdown 추출까지 동작하는 것을 스크래치 환경에서 확인했습니다(defuddle 0.19.6).
- **긴 글은 클립보드로 넘김**: 사용자가 확정했습니다. URL 길이 한도 때문에 긴 글은 쿼리로 못 싣고, 잘라서 보내면 요약·번역 결과가 불완전해지기 때문입니다.
- **프롬프트는 저장하지 않음**: 직접 입력은 1회용입니다. 프리셋 선택도 저장하지 않습니다.
- **최악의 UI는 사용자의 명시적 선택**: 강의용 학습 템플릿에서 나쁜 UI/UX를 보여 주려는 의도입니다.

## 결정 계약과의 충돌

`ui-composition` 결정(shadcn 기본 구성, semantic token, 일관된 variant, 공통 shell, 상태 설계, 좁은 화면 보존)과 이 화면은 정면으로 충돌합니다. 사용자가 이 화면에 한해 의도적으로 어기기로 확정했습니다. 이 스펙은 결정 계약을 고치지 않고, 이 화면에만 예외를 둡니다. 다른 화면과 이후 작업은 계속 `ui-composition`을 따릅니다. 프로토타입의 토큰은 `app/globals.css`에서 가져왔지만 화면 색상(무지개, 노랑, 빨강)은 semantic token이 아닌 직접 지정 값입니다.

## 가정 (덮어쓸 수 있음)

- 쿼리 길이 한도는 합친 텍스트가 대략 6,000자 이하일 때만 쿼리로 넘기는 보수적 값입니다. 구현에서 조정합니다.
- 다크모드는 첫 방문 시 라이트이고, 보노보노 눈으로 전환합니다. 선택을 브라우저에 기억할지는 구현에서 정하며 기억하지 않아도 됩니다.
- 광고 모드의 문구("위독하실 분", "급구", "URL변환전문대기업 [주]보노보노주식회사", "지금 변환하세요")는 참고 이미지에서 따와 이 서비스에 맞게 새로 쓴 것입니다.
- 보노보노 이미지는 사용자가 제공한 파일이며 저작권과 사용 범위는 사용자가 책임집니다. 구현에서는 프로토타입처럼 이미지를 포함하되 배경 투명화는 구현 방식에 맡깁니다.
- 로그인 필요 페이지나 JavaScript로만 그려지는 페이지는 변환되지 않을 수 있고, 이때는 본문 추출 실패 오류로 처리합니다.
- ChatGPT·Claude의 쿼리 파라미터(`q`) 동작은 외부 서비스 사양에 달려 있어 구현 중 실제 열림을 확인하되, 로그인 상태까지는 검증하지 않습니다.

## 범위 밖

- 변환 이력 저장, 계정, 서버 측 저장소.
- 프롬프트 직접 입력의 저장, 프리셋 편집.
- ChatGPT·Claude 외 다른 LLM, API 직접 호출.
- 요청 제한, URL 허용 목록, 사설망 접근 차단 같은 보안 하드닝(학습용 템플릿 예산 밖).
- 로그인이 필요한 페이지와 PDF 변환.
- 다른 화면에 이 UI 스타일을 확산하는 것.

## 남은 위험

- 눈 클릭 영역은 그림 위 투명 영역이라 보노보노가 뛰는 동안 한 번에 안 눌릴 수 있습니다. 구현 시 영역을 넉넉하게 둡니다.
- 일부 사이트는 서버의 요청을 막거나 본문이 비어 있게 응답해 추출에 실패합니다.
- ChatGPT·Claude의 쿼리 파라미터 사양이 바뀌면 "열기"가 입력란을 채우지 못할 수 있습니다.
- 서버가 임의의 URL을 가져오는 구조라, 배포 시 사설망 접근 같은 문제를 별도로 다뤄야 합니다(이 스펙의 범위 밖).
- 넓은 화면, 768 폭, 좁은 화면, 다크모드에서의 모양은 프로토타입에서 눈으로 충분히 확인하지 못했습니다.
